Follow the [rate tests](../model/report/project/index.html#humidity-and-regeneration-sensitivity), [regeneration comparison](../model/report/project/index.html#steam-electricity-and-cycle-timing) or [aging runs](../model/report/project/index.html#how-aging-changes-capture) for changes to a particular case. The operating guide explains how to try each case.

For a code review, follow the [project map](PROJECT_MAP.md) and [review checks](REVIEW_CHECKS.md). [Maintenance](MAINTENANCE.md) and [packaging](PUBLISHING.md) cover changes and releases. [Data needed](DATA_NEEDED.md) lists the measurements for the prototype case.
