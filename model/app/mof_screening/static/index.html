Adsorption law

CO2 law: q = qsat · bP / (1 + bP), where b is derived from the supplied reference loading, saturation and reference partial pressure. Water is an independent unary Sips law.

CO2 reference curve: enter absolute pressure in Pa and loading in mol/kg dry shaped material. The constant-isosteric-heat activity shift maps the curve to temperature; this is not a humid competitive mixture law. The split-rate option adds two kinetic inventories that share this one curve and energy.

For the one-pool option the adsorbed-species Cp order is CO2, H2O, N2, O2. For split rate it is CO2 fast, CO2 slow, H2O, N2, O2. Every CO2 entry is 37.5/MW_CO2 = 852.0887535645713 J/kg adsorbed CO2/K.

Two ordered sites: θᵢ = b₀ᵢ exp(−Uᵢ/RT) c / (1 + b₀ᵢ exp(−Uᵢ/RT)c), with concentration c = pCO2/(RT). b₀ is a concentration-basis prefactor in m³/mol, not a pressure-basis affinity.
